Introduction to CSS.

Cascading Style Sheets (CSS) is a language used to style and layout HTML documents. CSS allows you to control the colors, fonts, spacing, positioning, and overall appearance of web pages, making them more attractive and easier to read.

CSS can be applied in three ways:

  • Inline CSS: Styles are applied directly within HTML elements using the style attribute.
  • Internal CSS: Styles are defined within a <style> tag in the HTML document's <head>.
  • External CSS: Styles are written in a separate .css file and linked to the HTML document.

    • Using CSS improves the maintainability and consistency of websites by separating content (HTML) from presentation (CSS).
